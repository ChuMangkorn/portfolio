# ADR-0001: Case studies never name clients

**Date:** 2026-11-05
**Status:** Accepted

## Context

Most of the author's strongest recent work is for employer clients: a Japanese D2C cosmetics Shopify store, an agency website still in proposal stage, client landing pages. The portfolio must show this work to support the positioning, but the author has not asked the employer or clients for permission, and one project is not yet public.

## Decision

Every case study describes the client by industry and shape, never by name, logo, URL, or screenshot that reveals the brand. Code from employer repositories is not linked. Personal projects may be named and linked freely.

## Alternatives considered

- **Ask the employer for permission first.** Rejected for now: blocks shipping, and the answer may be no for the unlaunched project. Can be revisited per case later; the content model already supports adding a link.
- **Show only personal projects.** Rejected: hides the end-to-end client work that the positioning rests on.

## Consequences

- The site can ship today without approvals.
- Case studies must be written so they are convincing without a brand name: concrete scope, numbers, and the author's role.
- If permission arrives later, adding a name or link is a content edit only.
