# ADR-0001: Case studies never name clients

**Date:** 2026-11-05
**Status:** Accepted

## Context

Most of the author's strongest recent work is client work, done under the confidentiality norms that normally apply to it. The portfolio still has to show that work to support its positioning.

## Decision

Every case study describes the client by industry and shape, never by name, logo, URL, or a screenshot that reveals the brand. Code from employer or client repositories is not linked. Personal projects may be named and linked freely.

## Alternatives considered

- **Show only personal projects.** Rejected: it hides the end-to-end client work that the positioning rests on.
- **Name clients with their permission.** Possible per case later; the content model already supports adding a name or link.

## Consequences

- The site can ship without approvals.
- Case studies must be convincing without a brand name: concrete scope, numbers, and the author's role.
- If permission is given later, adding a name or link is a content edit only.
